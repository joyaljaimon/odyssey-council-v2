# Pitch deck outline

1. **Title.** Homer's Odyssey. "Every great solution begins with an Odyssey." Red-figure art of Athena.
2. **Problem.** People face the same storms they always have: temptation, burnout, grief, hard choices. Advice apps
   lecture; stories stick.
3. **Solution.** Text or FaceTime a character from the Odyssey. It listens, finds the episode that matches your
   problem, tells it with the real text on screen, and leaves you with "Your Ithaca": one lesson, one action.
4. **Demo.** (live; see script.md)
5. **How it works.** Phone → Chert (iMessage/FaceTime) → Channel → Brain (Gemini Live: voice, interruptions,
   function calling) → stage events over WebSocket → stage page in headless Chromium → the agent's FaceTime video.
   Story layer: 1,027 passages of Butler's translation, 12 episodes, 33 problem mappings, every quote verified.
6. **Why it's trustworthy.** Says it's an AI in the first message. Quotes only from the source text, with citations.
   No recording. Points to real help for serious issues.
7. **Roadmap.** More myths (the Iliad, the Aeneid, Gilgamesh), quiz mode, group calls where friends debate a
   character, teachers using it for literature classes.
8. **Team.** Channel, Brain, Story, Experience.
